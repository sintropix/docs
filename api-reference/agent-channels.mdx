An Agent Channel binds a place on an outside platform (a Slack channel today) to exactly one [Organization](/api-reference/organizations). Staff creates the binding once. The Sintropix agent reads it on each message, and works for that Organization in the place.

A place answers one Organization, with every Entity of it. An Organization can hold many places (for example, one Slack channel per topic). Rebinding a place to a different Organization is a delete then a create, so an old binding never reads as the new one. A thread that started before the move stays with the first Organization: the agent asks people to open a new thread.

A place has no default Entity: the agent works on the Entity each request is about. See [Which company Erwin works on](#which-company-erwin-works-on).

A scheduled run belongs to the Organization of the conversation that created it. The agent creates a schedule only in a channel bound to that same Organization. If you rebind the channel to a different Organization, the agent skips the schedule's runs, so an old schedule never reports on the new Organization.

<Warning>
  Staff-only. The routes below require the `staff` Role in the Organization. A `client` or `viewer` caller (session or API key) receives `403` with `PERMISSION_DENIED_ERROR`. An API key confined to one Entity also receives `403`, because these routes act on the whole Organization. See [Access and roles](/api-reference/overview#access-and-roles).
</Warning>

In the app, staff manages the same bindings in **Configuración → Canales del agente**. Every Entity of the Organization shows the same channels there.

## The Agent Channel object

| Field | Type | Description |
| --- | --- | --- |
| `id` | uuid | Agent Channel id. |
| `organizationId` | uuid | Owning Organization. |
| `platform` | `slack` | The outside platform. One value today; WhatsApp and the in-app chat add a value when they arrive. |
| `channelId` | string | The id the platform gives the place (for Slack, the channel id such as `C0123ABC`). Unique per `platform`. |
| `label` | string | The name staff reads the place by, for example `#bulk-contabilidad`. Free text. |
| `createdAt`, `updatedAt` | ISO 8601 timestamp | Row timestamps. |

## POST `/organizations/:organizationId/agent-channels`

Bind a place to the Organization.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `platform` | `slack` | Yes | The outside platform. |
| `channelId` | string | Yes | The id the platform gives the place. Trimmed, non-empty. |
| `label` | string | Yes | Human-readable name for the place. Trimmed, non-empty. |

**Response** (`201`): the created Agent Channel object.

```bash
curl -X POST "https://api.sintropix.com/api/organizations/$ORGANIZATION_ID/agent-channels" \
  -H "x-api-key: $SINTROPIX_STAFF_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{
    "platform": "slack",
    "channelId": "C0123ABC",
    "label": "#bulk-contabilidad"
  }'
```

If another Organization already holds the same `(platform, channelId)` pair, the request is refused with `409` and the domain code `AGENT_CHANNEL_PLACE_TAKEN_ERROR`. Delete the other Organization's binding first, then retry.

## GET `/organizations/:organizationId/agent-channels`

List every Agent Channel bound to the Organization.

**Response:** an array of Agent Channel objects.

```bash
curl "https://api.sintropix.com/api/organizations/$ORGANIZATION_ID/agent-channels" \
  -H "x-api-key: $SINTROPIX_STAFF_API_KEY"
```

## PATCH `/organizations/:organizationId/agent-channels/:agentChannelId`

Rename an Agent Channel. `label` is the only editable field. `platform` and `channelId` are set at create time and never move; to point the binding at a different place, delete this row and create a new one.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | string | Yes | New label. Trimmed, non-empty. |

**Response:** the updated Agent Channel object.

```bash
curl -X PATCH "https://api.sintropix.com/api/organizations/$ORGANIZATION_ID/agent-channels/$AGENT_CHANNEL_ID" \
  -H "x-api-key: $SINTROPIX_STAFF_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{ "label": "#contabilidad-clientes" }'
```

## DELETE `/organizations/:organizationId/agent-channels/:agentChannelId`

Release the binding. After the delete the place is free, and another Organization can bind it.

**Response** (`200`): the removed Agent Channel object.

```bash
curl -X DELETE "https://api.sintropix.com/api/organizations/$ORGANIZATION_ID/agent-channels/$AGENT_CHANNEL_ID" \
  -H "x-api-key: $SINTROPIX_STAFF_API_KEY" \
  -H "x-audit-actor: my-agent"
```

## GET `/agent-channels?platform=…&channelId=…`

Reverse lookup: given a place, return the Agent Channel that binds it, with its `organizationId`. This route is not scoped to an Organization because the caller only knows the place. The Sintropix agent calls it to learn which client a conversation is about.

The lookup finds only bindings in Organizations where you hold the `staff` Role.

**Query parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `platform` | `slack` | Yes | The outside platform. |
| `channelId` | string | Yes | The id the platform gives the place. |

**Response:** the Agent Channel object. To name the client and its Entities, call [`GET /organizations/:organizationId`](/api-reference/organizations#get-organizations-organizationid) or [`GET /entities`](/api-reference/entities).

```bash
curl "https://api.sintropix.com/api/agent-channels?platform=slack&channelId=C0123ABC" \
  -H "x-api-key: $SINTROPIX_STAFF_API_KEY"
```

If no Organization has bound the place, the request answers `404` with the domain code `AGENT_CHANNEL_PLACE_UNBOUND_ERROR`. The agent reads this as "no one speaks here" and stays silent.

## Work with Erwin in a Slack channel

The Sintropix agent, Erwin, answers in the bound channel's threads. Mention him to start. Once he's in a thread, he answers the later messages meant for him, including a short "sí" or "ok" to a question he asked. He doesn't answer people talking to each other, a "gracias", or an "ok" after he finishes. He still reads those messages as context for his next answer. He reacts to most messages with an emoji, before he starts any work or instead of replying. The emoji is his reply to the message, the way a coworker's is. It never labels the message's topic or gives a verdict:

- 👀: he's seen it and will look into it.
- 👍: he agrees or will do it.
- 📝: he takes note.
- 🙏: thanks for something he needed, such as a file or a fact.
- 🙌, 🎉, 😂, or 👋: a reply to thanks, good news, a joke, or a greeting.

He doesn't react to a message meant for another person, to people talking to each other, or to an open question he still has to think about.

Erwin reads the files you send in the thread, including in a Slack Connect channel shared with another company. He also reads the full address of each link you paste, even when Slack shows it shortened, so you can paste a Sintropix [app link](/guides/app-links) to point him to a record. He sees your message's formatting too, such as bold text and lists.

### Which company Erwin works on

Erwin knows every Entity of the bound Organization, by name and tax id. He works on the one you mean, as your messages and the records show it. When a request fits more than one Entity and the records don't settle it, he asks. To skip the question, name the company in your message, for example *"Carga la cartola de Acme Inversiones"*.

Erwin reaches only the Entities of the bound Organization. An Entity added to the Organization, or moved out of it, applies from his next answer.

### Stop or interrupt Erwin

While Erwin works, his answer shows a progress line with a **Detener** button below it. Anyone in the thread can click **Detener**. Erwin stops and doesn't start again. The message then says who stopped him, and that what he already wrote in the ERP stays.

To change course without stopping, send a new message in the thread. It interrupts the running answer, which ends with *(interrumpido)*. Erwin's next answer takes every message sent in the meantime. Before he continues, he checks what he already wrote in the ERP, so he never repeats a write.

### Answer Erwin's questions

When Erwin needs a fact from a person, he posts a question card below his answer and waits. The card tags one or more people who may know. It shows the question, what Erwin saw, and a link to the record. Anyone can answer: click **Responder** and fill in the form, or reply in the thread. A form answer turns the card into **Respondido por** and the answer.

### Sign in to a bank by hand

Some bank sites refuse automated sign-ins. Santander is one of them. When Erwin needs such a site, he opens its login page, tags a person, and posts a link to his live browser. Sign in there within five minutes. Erwin then continues in your session. He never types the RUT or password of these sites himself.

For Santander, Erwin reads the label of the Entity's Santander login Credential to know which site to open. Include `Persona` or `Empresa` in the label, for example `Santander Persona` or `Santander Empresa`. Without either word, Erwin looks for the answer in the client's [wiki](/core-concepts). If the wiki doesn't say, he asks which one before he starts, and writes your answer in the wiki so he doesn't ask again.

### Read the Organization's Slack channels

Erwin can read the Slack channels bound to his Organization, even where nobody mentioned him. He uses them as context for a task, in Slack and in the in-app chat. He reads only the channels he's a member of, and never a channel bound to another Organization.

### Scheduled tasks

Ask Erwin in a bound channel to run a task on a schedule, such as a weekly overdue receivables review. Each schedule has its own:

- **Hours and time zone.** The schedule fires on the clock of its time zone, including daylight saving time. Without a time zone, it uses `America/Santiago`.
- **Model.** A new schedule takes the channel's current model. A later `/model` in the channel doesn't change it.
- **Channel.** A schedule can move to another channel bound to the same Organization. Invite Erwin to that channel first.

Each run posts its first message straight into the channel as a new message, usually the full answer. Its questions and your replies go in that message's thread. A reply there interrupts the run, as in any thread. A run with nothing to report posts nothing.

To change a schedule, ask Erwin. He can change its instructions, hours, time zone, model, or channel. Changes apply from the next run. A run already underway, and the threads of past runs, stay where they started.

## Choose the agent's model in a Slack channel

In a bound Slack channel, anyone in the channel can pick the model the Sintropix agent uses with the `/model` slash command.

| Command | Result |
| --- | --- |
| `/model` | Shows the channel's current model and the available options. |
| `/model <name>` | Sets the channel's model. The name is case-insensitive. |

| Name | Model |
| --- | --- |
| `gpt-sol` (default) | OpenAI GPT-6.1 Sol |
| `gpt-sol-ultra-fast` | OpenAI GPT-6.1 Sol on the Ultrafast tier. Answers faster. |
| `opus` | Anthropic Claude Opus 5.5 |

```text
/model opus
```

A change applies only to threads that start after it. A thread keeps the model it started with, so an open conversation never switches models midway. A scheduled task keeps its own model, so `/model` never changes an existing schedule. Ask Erwin to change a schedule's model instead.

The choice belongs to one channel. Other channels bound to the same Organization keep their own model. An unknown name changes nothing, and the agent replies with the list of options. In an unbound channel or a direct message, the agent replies that no one speaks there and changes nothing.

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | Success on `GET`, `PATCH`, `DELETE`. `DELETE` answers with the deleted row. |
| `201` | Agent Channel created. |
| `400` | Validation error, or missing `x-audit-actor` on a key-authenticated mutation. |
| `403` | Caller does not hold the `staff` Role in the Organization, or uses an API key confined to one Entity (`PERMISSION_DENIED_ERROR`). |
| `404` | Organization or Agent Channel not found, or reverse lookup found no binding (`AGENT_CHANNEL_PLACE_UNBOUND_ERROR`). An Organization where you hold no Membership answers `ORGANIZATION_NOT_FOUND_ERROR`. |
| `409` | Another Organization already holds the place (`AGENT_CHANNEL_PLACE_TAKEN_ERROR`). |

## Domain error codes

| Code | When |
| --- | --- |
| `AGENT_CHANNEL_NOT_FOUND_ERROR` | The `:agentChannelId` in the path does not belong to the Organization. |
| `AGENT_CHANNEL_PLACE_TAKEN_ERROR` | Create refused: another Organization already binds the same `(platform, channelId)`. |
| `AGENT_CHANNEL_PLACE_UNBOUND_ERROR` | Reverse lookup refused: no Organization binds the place. |
| `ORGANIZATION_NOT_FOUND_ERROR` | The `:organizationId` in the path is not an Organization you hold a Membership in. |

An Organization that still has Agent Channels bound to it can't be deleted. Release the bindings first.
