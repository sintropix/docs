title: "Sintropix Audit Trail API: Query Forensic Change History"

description: "Query the forensic audit trail for an entity. Returns paginated mutation envelopes with actor attribution, diffs, and named resources. GET requests are not audited."

The audit trail is a forensic, append-only log of every mutating request against an entity's data. Each row stores the actor, credential type, declared actor, request id, route, method, and a diff of what changed. GET requests do not produce audit records.

## List audit trail

`GET /api/entities/:entityId/audit-trail`

Returns a paginated page of audit envelopes for the entity, plus the named resources needed to render them without extra lookups.

**Query params**

| Param | Type | Required | Description |
| --- | --- | --- | --- |
| `cursor` | integer | No | Page cursor (positive integer). Pass the `nextCursor` from the previous page to fetch the next one. |
| `limit` | integer | No | Page size, 1 to 100. Defaults to 50. |
| `from` | ISO date | No | Filter envelopes on or after this date. Must be before or equal to `to` when both are given. |
| `to` | ISO date | No | Filter envelopes on or before this date. |
| `actorUserId` | UUID | No | Filter to a specific user. |
| `conversationId` | UUID | No | Filter to a specific conversation / request grouping. |
| `tableName` | string | No | Filter to a specific table; must be provided together with `rowId`. See accepted values below. |
| `rowId` | UUID | No | Filter to a specific row; must be provided together with `tableName`. |

**Accepted `tableName` values**

The trail records changes to these tables: `ledger_entry`, `ledger_entry_line`, `invoice`, `invoice_attachment`, `attachment`, `partner`, `bank_movement`, `bank_account`, `reconciliation_allocation`, `fixed_asset`, `fixed_asset_class`, `fixed_asset_depreciation_entry`. Any other string is accepted but matches no rows.

Two parents also pull in their child rows: `tableName=ledger_entry` returns changes to that entry and to its `ledger_entry_line` rows; `tableName=invoice` returns changes to that invoice and to its `invoice_attachment` links.

**Response** `200`

| Field | Type | Description |
| --- | --- | --- |
| `envelopes` | array | One envelope per mutating request, newest first. See below. |
| `namedResources` | object | Display facts for the resources the envelopes on this page reference. See below. |
| `nextCursor` | integer or `null` | Cursor for the next page, or `null` on the last page. |

Each **envelope**:

| Field | Type | Description |
| --- | --- | --- |
| `id` | integer | Envelope id. |
| `occurredAt` | ISO datetime | When the request was processed. |
| `requestId` | string | Server-generated unique id for the request. |
| `actorUserId` | UUID or `null` | The authenticated user, when there was one. |
| `actor` | object or `null` | `{ id, name, role }` of the authenticated user, where `role` is `staff` or `client`. |
| `credentialType` | enum | `session`, `api_key`, or `system`. |
| `apiKeyId` | UUID or `null` | The API key used, for `api_key` requests. |
| `declaredActor` | string or `null` | Value of the `x-audit-actor` header on API-key mutations. |
| `route` | string | The endpoint pattern that produced the mutation. |
| `method` | string | HTTP method, for example `POST`. |
| `params` | object | Path parameters of the request. |
| `entityId` | UUID or `null` | The entity scope of the change. |
| `ipAddress` | string or `null` | Caller IP address. |
| `userAgent` | string or `null` | Caller user agent. |
| `changes` | array | One change per affected row. See below. |

Each **change**:

| Field | Type | Description |
| --- | --- | --- |
| `id` | integer | Change id. |
| `envelopeId` | integer | The envelope this change belongs to. |
| `occurredAt` | ISO datetime | When the row changed. |
| `tableName` | string | One of the table names listed above. |
| `rowPrimaryKey` | object | Primary key of the affected row, for example `{ "id": "..." }`. |
| `operation` | enum | `insert`, `update`, or `delete`. |
| `before` | object or `null` | Row image before the change. `null` on insert. |
| `after` | object or `null` | Row image after the change. `null` on delete. |

Keys inside `before`, `after`, and `rowPrimaryKey` are the stored column names in `snake_case` (for example `entry_date`, `partner_id`), not the camelCase names used elsewhere in the API.

**`namedResources`** carries the display facts of exactly the resources the page's envelopes point at, so a feed can render names without further lookups:

| Field | Type | Description |
| --- | --- | --- |
| `ledgerAccounts` | array | `{ id, code, name }` |
| `partners` | array | `{ id, name }` |
| `bankAccounts` | array | `{ id, name, currency }` where `currency` is an ISO 4217 code. |
| `sources` | array | `{ id, name }` |
| `ledgerEntryLines` | array | `{ id, accountName, entryMemo, entryDate }` where `entryMemo` may be `null` and `entryDate` is `YYYY-MM-DD`. |

A resource that no longer exists is absent from these lists; treat an id you cannot resolve as unknown.

## What the trail captures

The audit trail is row-level and automatic: every write is recorded by the database itself, so no endpoint can skip it. Every mutating request produces one **Audit Envelope** grouping its **Audit Changes**:

- **Actor:** `actorUserId` plus name and role of the authenticated user
- **Credential type:** `session` for browser sessions, `api_key` for API key requests, `system` for changes made by Sintropix itself
- **Declared actor:** the value of the `x-audit-actor` header on API-key mutations (stored as a claim, not a verified identity)
- **Request id:** a server-generated unique id grouping all changes in one request
- **Route and HTTP method:** the endpoint that produced the mutation
- **Entity id:** the entity scope the change occurred within
- **Diff:** for inserts and deletes, the full row image; for updates, only the columns that moved with before and after values

GET requests are not audited. Unbooking (soft delete) is no longer traceless: the removed entry's full image survives as Audit Changes.

## Status codes

| Code | Meaning |
| --- | --- |
| 200 | Success |
| 400 | Invalid query parameters (bad type, `from` after `to`, or `tableName` without `rowId`) |
| 401 | Unauthenticated |
| 403 | Not a member of this entity |
| 404 | Entity not found |
