title: "Sintropix Bank Connections API: Link and Manage Bank Feeds"
sidebarTitle: "Bank Connections"
description: "Create, list, reconnect, map, and disconnect Bank Connections for an Entity. Connect to providers like Fintoc or Global66 and feed discovered accounts into Bank Accounts."
---

A Bank Connection is an Entity-scoped grant to read bank data from a Provider (for example, Fintoc or Global66). It stores encrypted credentials and a health status. A Connection can expose discovered accounts, which you then map to existing Bank Accounts or use to create new ones. Removing a Connection cascades and removes every feed it held.

All routes live under `/api/entities/:entityId/bank-connections`. Path parameters are UUIDs.

## Authentication

Use a session cookie or an API key via the `x-api-key` header. Mutations with an API key also require `x-audit-actor`. See [Get an API Key](/guides/api-keys).

## Create a link intent

`POST /api/entities/:entityId/bank-connections/link-intents`

Start the connect flow by creating a Link Intent at the Provider. The response contains a widget token and public key the frontend needs to open the Provider widget.

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `holderType` | `business` or `individual` | Yes | Who holds the account at the institution |

### Response

| Field | Type | Description |
| --- | --- | --- |
| `widgetToken` | `string` | Token the Provider widget needs |
| `publicKey` | `string` | Public key for the widget session |

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/link-intents \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"holderType":"business"}'
```

## Create a Bank Connection

`POST /api/entities/:entityId/bank-connections`

Finalize the connection after the widget journey completes. The shape is a discriminated union on `provider`.

### Request body (Fintoc)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `provider` | `'fintoc'` | Yes | Provider identifier |
| `id` | `uuid` | Yes | Client-supplied id for idempotency |
| `exchangeToken` | `string` | Yes | Token the widget minted |

### Request body (Global66)

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `provider` | `'global66'` | Yes | Provider identifier |
| `id` | `uuid` | Yes | Client-supplied id for idempotency |
| `clientId` | `string` | Yes | Global66 client id |
| `clientSecret` | `string` | Yes | Global66 client secret |
| `accounts` | `array` | Yes | At least one account object |
| `accounts[].accountId` | `string` | Yes | Account id at Global66 |
| `accounts[].currency` | `string` | Yes | ISO 4217 code (e.g. `CLP`) |

### Response

The created connection plus any fed Bank Accounts (empty on creation). Every endpoint on this page that returns a Bank Connection uses this shape:

| Field | Type | Description |
| --- | --- | --- |
| `id` | `uuid` | Connection id |
| `entityId` | `uuid` | Owning Entity |
| `provider` | `fintoc` or `global66` | Provider that holds the grant |
| `providerRef` | `string` | Provider-side reference for the link |
| `institutionName` | `string` | Institution display name |
| `holderId` | `string` | Provider-side id of the account holder |
| `mode` | `test` or `live` | Whether the link runs against the Provider's test or live environment |
| `createdAt` | `ISO datetime` | Creation timestamp |
| `updatedAt` | `ISO datetime` | Last update timestamp |
| `fedBankAccounts` | `array` | Bank Accounts fed by this connection, in name order; each has `id` (`uuid`) and `name` (`string`) |

```json
{
  "id": "0192a8b4-0000-7000-8000-000000000001",
  "entityId": "0190a000-0000-7000-8000-000000000001",
  "provider": "fintoc",
  "providerRef": "link_abc123",
  "institutionName": "Banco de Chile",
  "holderId": "761234560",
  "mode": "live",
  "createdAt": "2026-02-01T12:00:00.000Z",
  "updatedAt": "2026-02-01T12:00:00.000Z",
  "fedBankAccounts": []
}
```

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{
    "provider": "fintoc",
    "id": "0192a8b4-0000-7000-8000-000000000001",
    "exchangeToken": "ex_tok_123"
  }'
```

## Reconnect a Bank Connection

`POST /api/entities/:entityId/bank-connections/:bankConnectionId/reconnect`

Restore a failed Fintoc connection with a fresh exchange token.

### Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `entityId` | `uuid` | Entity that owns the connection |
| `bankConnectionId` | `uuid` | Connection to reconnect |

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `provider` | `'fintoc'` | Yes | Must match the existing provider |
| `exchangeToken` | `string` | Yes | Fresh token from the widget |

### Response

The restored Bank Connection, in the same shape as the create response.

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID/reconnect \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"provider":"fintoc","exchangeToken":"ex_tok_456"}'
```

## List Bank Connections

`GET /api/entities/:entityId/bank-connections`

Return every Bank Connection for the Entity, each with the fed Bank Accounts it serves.

### Response

A JSON array of Bank Connections, each in the same shape as the create response.

```bash
curl https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## Get discovered accounts

`GET /api/entities/:entityId/bank-connections/:bankConnectionId/accounts`

Read the live account panel for one Connection. This fetches the Provider's current link status, discovered accounts, and the local map inputs the server owns.

### Response

| Field | Type | Description |
| --- | --- | --- |
| `status` | `active`, `inactive`, or `login_required` | Provider's judgment of the link. `login_required` means the institution rejected the stored grant and you must reconnect |
| `accounts` | `array` | Accounts the Provider discovered (see below) |
| `mappableBankAccounts` | `array` | Local Bank Accounts that can still take a feed (see below) |
| `ledgerAccounts` | `array` | Asset Ledger Accounts eligible for mapped creation (see below) |
| `refreshing` | `boolean \| null` | `true` while the Provider is still refreshing the link, `false` when every refresh has finished, `null` when the refresh state could not be read |

Each element of `accounts` carries:

| Field | Type | Description |
| --- | --- | --- |
| `providerAccountId` | `string` | Provider's opaque handle for the account |
| `name` | `string` | Account name as the institution reports it |
| `number` | `string` | Account number as the institution reports it |
| `type` | `string` | Provider-defined account type, display only |
| `currency` | `string` | ISO 4217 code |
| `balance.current` | `integer` | Current balance in minor units of `currency` |
| `balance.available` | `integer \| null` | Available balance in minor units; null when the institution does not report it |
| `balance.limit` | `integer \| null` | Credit limit in minor units; null when the institution does not report it |
| `refreshedAt` | `ISO datetime \| null` | When the Provider last refreshed this account |
| `observed` | `boolean` | `true` when the Provider reads the account but the feed does not land its movements yet. Always `false` for Fintoc |
| `fedBankAccount` | `object \| null` | The Bank Account this account already feeds, as `{ id, name }`, or null |

Each element of `mappableBankAccounts` carries `id` (`uuid`), `name` (`string`), and `currency` (`string`). Each element of `ledgerAccounts` carries `id` (`uuid`), `code` (`string`), and `name` (`string`).

```json
{
  "status": "active",
  "accounts": [
    {
      "providerAccountId": "acc_123",
      "name": "Cuenta Corriente",
      "number": "000123456789",
      "type": "checking_account",
      "currency": "CLP",
      "balance": { "available": 1250000, "current": 1250000, "limit": null },
      "refreshedAt": "2026-02-01T12:00:00.000Z",
      "observed": false,
      "fedBankAccount": null
    }
  ],
  "mappableBankAccounts": [
    { "id": "0192a8b4-0000-7000-8000-000000000002", "name": "Primary Checking", "currency": "CLP" }
  ],
  "ledgerAccounts": [
    { "id": "0192a8b4-0000-7000-8000-000000000004", "code": "1102", "name": "Banco" }
  ],
  "refreshing": false
}
```

```bash
curl https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID/accounts \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## Add accounts to a Global66 connection

`POST /api/entities/:entityId/bank-connections/:bankConnectionId/accounts`

For Global66 connections, publish additional account ids the Provider does not list automatically.

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `accounts` | `array` | Yes | At least one account object |
| `accounts[].accountId` | `string` | Yes | Account id at Global66 |
| `accounts[].currency` | `string` | Yes | ISO 4217 code |

### Response

The updated Bank Connection, in the same shape as the create response.

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID/accounts \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"accounts":[{"accountId":"acc_789","currency":"CLP"}]}'
```

## Map a discovered account to an existing Bank Account

`POST /api/entities/:entityId/bank-connections/:bankConnectionId/feeds`

Create a feed that attaches a discovered account to an existing local Bank Account. The server derives the currency from the Provider and rejects a mismatch.

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `bankAccountId` | `uuid` | Yes | Local Bank Account to feed |
| `providerAccountId` | `string` | Yes | Provider's opaque handle for the account |

### Response

The Bank Account that now carries the feed, with `feed` populated. The shape is the one documented on the [Bank Accounts](/api-reference/bank-accounts) page, without the `balance` and `unreconciledCount` summary fields.

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID/feeds \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{
    "bankAccountId": "0192a8b4-0000-7000-8000-000000000002",
    "providerAccountId": "acc_123"
  }'
```

## Create a Bank Account from a discovered account

`POST /api/entities/:entityId/bank-connections/:bankConnectionId/bank-accounts`

Create a new Bank Account and feed it from a discovered account in one operation. The creation is always kind `bank`, so only an asset Ledger Account is accepted.

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `uuid` | Yes | Client-supplied id for idempotency |
| `name` | `string` | Yes | Display name |
| `ledgerAccountId` | `uuid` | Yes | Asset Ledger Account to map |
| `providerAccountId` | `string` | Yes | Provider's opaque handle |
| `feedStartDate` | `ISO date` | Yes | Day the feed begins. Must not be older than 90 days or in the future |

### Response

The created Bank Account with its `balance` and `unreconciledCount` summary, in the same shape as the list response on the [Bank Accounts](/api-reference/bank-accounts) page.

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID/bank-accounts \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{
    "id": "0192a8b4-0000-7000-8000-000000000003",
    "name": "Banco Principal",
    "ledgerAccountId": "0192a8b4-0000-7000-8000-000000000004",
    "providerAccountId": "acc_123",
    "feedStartDate": "2024-06-01"
  }'
```

## Disconnect a Bank Connection

`DELETE /api/entities/:entityId/bank-connections/:bankConnectionId`

Remove the connection and cascade every feed it held. The response names the deleted connection and every Bank Account that lost its feed.

### Response

| Field | Type | Description |
| --- | --- | --- |
| `deletedBankConnectionId` | `uuid` | The removed connection |
| `unfedBankAccounts` | `array` | Accounts whose feed was removed, each a Bank Account (see the [Bank Accounts](/api-reference/bank-accounts) page) without summary fields and with `feed` set to null |

```bash
curl -X DELETE https://api.sintropix.com/api/entities/$ENTITY_ID/bank-connections/$BANK_CONNECTION_ID \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent"
```
