An Entity is a legal company with its own books, functional currency, and integrations. Every ledger route in the API scopes by `entityId`. Every Entity belongs to exactly one [Organization](/api-reference/organizations), and Users reach it through their Membership in that Organization. This page covers the Entity CRUD, ledger-lock date, Fiscal Year start, parent Entity, and Organization move endpoints.

An Entity can have a parent Entity that controls it, and the Entities it controls are its subsidiaries. A parent Entity and its subsidiaries form a group, and a group stays inside one Organization: the parent is always an Entity of the same Organization. A Superadmin sets the structure from the Organization in the staff panel.

## POST /api/entities

Create a new Entity in an Organization. The client supplies the idempotency id, so a retried POST with the same id is rejected as a conflict instead of creating a duplicate.

Sintropix sets up your Entities for you: you can't create one from the client app. A Superadmin creates it from the Organization in the staff panel.

- **Superadmin only, from a signed-in session.** A request with an API key or an OAuth access token returns `403` with `SUPERADMIN_SESSION_REQUIRED`, and any other User, `staff` included, gets `403` with `SUPERADMIN_REQUIRED`. A Superadmin can create an Entity in any Organization without holding a Membership in it. List every Organization with [`GET /api/onboarding/organizations`](/api-reference/onboarding#get-/onboarding/organizations).
- Creating an Entity opens none of its books to the Superadmin. Users reach it through a Membership of its Organization.
- Creating an Entity also gives it its [representing Partner](/api-reference/partners#representing-partners): the Organization's Partner with the Entity's tax identity, which the other Entities use to name it as their counterparty. When the Organization already has a Partner with that tax identity, that Partner becomes the representing one.
- An unknown `organizationId` returns `404` with `ORGANIZATION_NOT_FOUND_ERROR`.
- An unknown `country` returns `400` with `ENTITY_CREATION_COUNTRY_UNKNOWN_ERROR`, and an unknown `currency` returns `400` with `ENTITY_CREATION_CURRENCY_UNKNOWN_ERROR`.
- An Entity with the same `country` and `taxId` already exists: the request returns `409` with `ENTITY_CREATION_TAX_ID_ALREADY_EXISTS_ERROR`.
- An unknown `parentEntityId` returns `404` with `ENTITY_CREATION_PARENT_NOT_FOUND_ERROR`. A parent in another Organization returns `409` with `ENTITY_CREATION_PARENT_IN_ANOTHER_ORGANIZATION_ERROR`.
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | UUID | Yes | Client-supplied idempotency id |
| `name` | string | Yes | Legal company name, non-empty |
| `country` | string | Yes | ISO country code, non-empty |
| `taxId` | string | Yes | Tax registration, 1 to 50 characters; canonicalized for Chile |
| `currency` | string | Yes | Functional currency code, non-empty |
| `organizationId` | UUID | Yes | Organization the Entity belongs to |
| `parentEntityId` | UUID or null | No | Parent Entity that controls the new Entity. It must be an Entity of the same Organization. Defaults to `null`, a root Entity. |

- **Success response:** the created Entity with `organizationName`, `organizationWebsite`, and `organizationEmailDomain` (see [Response shape](#response-shape))
- **Status:** 201

```bash
curl -X POST https://api.sintropix.com/api/entities \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{
    "id": "11111111-1111-4111-8111-111111111111",
    "name": "Acme SpA",
    "country": "CL",
    "taxId": "76.123.456-0",
    "currency": "CLP",
    "organizationId": "7c1e4b2a-3d5f-4a6b-8c9d-0e1f2a3b4c5d",
    "parentEntityId": null
  }'
```

## GET /api/entities

List every Entity the caller can access. You see every Entity of each Organization you hold a Membership in, whatever your Role. Being a Superadmin adds no Entities to this list. An OAuth access token sees only the Entities of the Organization it was approved for.

- **Success response:** array of Entity objects, each with `organizationName`, `organizationWebsite`, and `organizationEmailDomain` (see [Response shape](#response-shape)). Group the rows by `organizationId` to show Entities per Organization.
- **Status:** 200

```bash
curl https://api.sintropix.com/api/entities \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## GET /api/entities/:entityId/editability

Check whether the identity fields of an Entity (name, country, taxId, currency) are currently editable. Returns a single boolean flag.

- **Path param:** `entityId` (UUID)
- **Success response:**

| Field | Type | Description |
| --- | --- | --- |
| `identityFieldsEditable` | boolean | `true` when `name`, `country`, `taxId`, and `currency` can still be changed |

- **Status:** 200

```bash
curl https://api.sintropix.com/api/entities/$ENTITY_ID/editability \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## PATCH /api/entities/:entityId

Update the core identity fields of an Entity. At least one field must be provided. To change the Organization, use `PATCH /api/entities/:entityId/organization` below. The update canonicalizes Chilean tax registrations and requires both `country` and `taxId` when either is supplied.

A corrected `country` or `taxId` also corrects the Entity's [representing Partner](/api-reference/partners#representing-partners). When another Partner of the Organization already holds the new tax identity, the update returns `409` with `ENTITY_TAX_IDENTITY_TAKEN_ERROR`, and `params.partnerId` names that Partner. Correct or clear that Partner's tax ID first.

Once the Entity has had a Ledger Entry, a change to `country`, `taxId`, or `currency` returns `409` with `ENTITY_IDENTITY_FIELDS_LOCKED_ERROR`. Check first with [`GET /api/entities/:entityId/editability`](#get-/api/entities/entityid/editability). An unknown `country` returns `400` with `UNKNOWN_COUNTRY_ERROR`, an unknown `currency` returns `400` with `UNKNOWN_CURRENCY_ERROR`, and a `country` and `taxId` that another Entity already holds returns `409` with `ENTITY_ALREADY_EXISTS_ERROR`.

- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | Legal company name |
| `country` | string | No | ISO country code |
| `taxId` | string | No | Tax registration, at most 50 characters |
| `currency` | string | No | Functional currency |

- **Success response:** the updated Entity (see [Response shape](#response-shape))
- **Status:** 200

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"name": "Acme SpA Updated"}'
```

## PATCH /api/entities/:entityId/ledger-lock-date

Set, move, or clear the ledger lock date. A date freezes the ledger up to and including that date; `null` clears the lock. The lock date cannot move to a date on or after any Scheduled Entry's Entry Date.

- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `ledgerLockDate` | ISO date or null | Yes | Lock date or null to clear |

- **Success response:** the updated Entity (see [Response shape](#response-shape))
- **Status:** 200

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID/ledger-lock-date \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"ledgerLockDate": "2026-01-31"}'
```

## PATCH /api/entities/:entityId/fiscal-year-start

Set the month the Entity's Fiscal Year starts in. The Fiscal Year is the twelve months over which the Entity measures its result. It starts on day 1 of the start month, and every Entity starts in January until you change it.

The Fiscal Year decides where income and expense accounts restart at zero, and which account carries the result of earlier years. See [The Fiscal Year in reports](/api-reference/reports#the-fiscal-year-in-reports). Sintropix posts no closing entry: every report derives the close when it reads the balances.

- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `fiscalYearStartMonth` | integer | Yes | Month the Fiscal Year starts in, from `1` (January) to `12` (December) |

- **Success response:** the updated Entity (see [Response shape](#response-shape))
- **Status:** 200
- A month outside `1` to `12` returns `400`. [`PATCH /api/entities/:entityId`](#patch-/api/entities/entityid) doesn't take `fiscalYearStartMonth`: it returns `400` when the body carries it.
- While the Entity has a [ledger lock date](#patch-/api/entities/entityid/ledger-lock-date), the start can't change. The request returns `409` with `ENTITY_FISCAL_YEAR_START_LOCKED_ERROR`, and `params.ledgerLockDate` names the lock date. Clear the lock date, set the start, and set the lock date again.
- A new start re-cuts every past Fiscal Year, so every report reads the earlier years with the new start too.

In the app, set it in the Entity's row on the **Empresa** page of its Organization, under **Inicio del año fiscal**.

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID/fiscal-year-start \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"fiscalYearStartMonth": 7}'
```

A refusal while a lock date is set:

```json
{
  "code": "ENTITY_FISCAL_YEAR_START_LOCKED_ERROR",
  "params": { "ledgerLockDate": "2025-12-31" }
}
```

## PATCH /api/entities/:entityId/parent

Set, change, or clear the parent Entity that controls this one. An id names the controlling Entity; `null` makes it a root. The parent must exist, must be in the same Organization, must not be the Entity itself, and must not create a cycle.

- **Superadmin only, from a signed-in session.** A request with an API key or an OAuth access token returns `403` with `SUPERADMIN_SESSION_REQUIRED`, and any other User, `staff` included, gets `403` with `SUPERADMIN_REQUIRED`. A Superadmin can set the parent of any Entity without holding a Membership in its Organization.
- The checks run in this order:
  1. An unknown parent returns `404` with `ENTITY_PARENT_NOT_FOUND_ERROR`.
  2. A parent in another Organization returns `409` with `ENTITY_PARENT_IN_ANOTHER_ORGANIZATION_ERROR`.
  3. The Entity as its own parent returns `400` with `ENTITY_SELF_PARENT_ERROR`.
  4. A parent that is one of the Entity's own subsidiaries, at any depth, returns `400` with `ENTITY_PARENT_CYCLE_ERROR`.
- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `parentEntityId` | UUID or null | Yes | Controlling Entity id or null |

- **Success response:** the updated Entity (see [Response shape](#response-shape))
- **Status:** 200

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID/parent \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"parentEntityId": "22222222-2222-4222-8222-222222222222"}'
```

## PATCH /api/entities/:entityId/organization

Move an Entity to another Organization. Members of the old Organization lose access to the Entity. Members of the new Organization gain it with their Role there.

- **Superadmin only, from a signed-in session.** A request with an API key or an OAuth access token returns `403` with `SUPERADMIN_SESSION_REQUIRED`, and any other User gets `403` with `SUPERADMIN_REQUIRED`. A Superadmin can move any Entity without holding a Membership in either Organization.
- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `organizationId` | UUID | Yes | The Organization to move the Entity to |

- **Status:** 204
- An unknown `organizationId` returns `404` with `ORGANIZATION_NOT_FOUND_ERROR`.
- An Entity in a group can't move: an Entity with a parent Entity or any subsidiary returns `409` with `ENTITY_MOVE_IN_GROUP_ERROR`. Clear those links with [`PATCH /api/entities/:entityId/parent`](#patch-/api/entities/entityid/parent) first, then move it.
- An Entity that shares its Organization's data can't move, because [Partners](/api-reference/partners#partners-belong-to-the-organization), [Dimensions](/api-reference/dimensions#dimensions-belong-to-the-organization), and [Integrations](/api-reference/integrations#integrations-belong-to-the-organization) belong to the Organization:
  - The move returns `409` with `ENTITY_MOVE_USES_ORGANIZATION_DATA_ERROR` when the Entity:
    - Uses Partners of its Organization.
    - Has Ledger Lines that carry a Dimension Value.
    - Has a Source Feed or a bank feed that routes an Integration of its Organization.
    - Has a Book that a Google Sheets Integration exports.
    - Has Ledger Accounts, because each one maps to a [Group Account](/api-reference/chart-of-accounts#the-group-chart) of its Organization.
  - An Entity whose representing Partner another Entity uses returns `409` with `ENTITY_MOVE_REPRESENTING_PARTNER_IN_USE_ERROR`. `params.partnerId` names that Partner.
  - When the target Organization already has a Partner with the Entity's tax identity, the move returns `409` with `ENTITY_MOVE_TAX_IDENTITY_TAKEN_ERROR`. `params.partnerId` names that Partner.

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID/organization \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"organizationId": "7c1e4b2a-3d5f-4a6b-8c9d-0e1f2a3b4c5d"}'
```

## Response shape

Every endpoint on this page that returns an Entity uses this shape:

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | Entity id |
| `name` | string | Legal company name |
| `country` | string | ISO country code |
| `taxId` | string | Canonical tax registration |
| `currency` | string | Functional currency |
| `ledgerLockDate` | ISO date or null | Ledger freeze date |
| `fiscalYearStartMonth` | integer | Month the Fiscal Year starts in, from `1` to `12`. `1` (January) unless set with [`PATCH /api/entities/:entityId/fiscal-year-start`](#patch-/api/entities/entityid/fiscal-year-start) |
| `parentEntityId` | UUID or null | Parent Entity that controls this one, always in the same Organization. `null` for a root Entity. |
| `organizationId` | UUID | Organization the Entity belongs to |
| `organizationName` | string | Name of that Organization. Returned by `GET /api/entities` and `POST /api/entities` only. |
| `organizationWebsite` | string or null | Website of that Organization, as a bare domain. Read the Organization's logo from [`GET /api/organizations/:organizationId/logo`](/api-reference/organizations#get-/organizations/organizationid/logo). Returned by `GET /api/entities` and `POST /api/entities` only. |
| `organizationEmailDomain` | string or null | That Organization's [email domain](/api-reference/organizations#patch-/organizations/organizationid/email-domain). `null` until a Superadmin sets it. Returned by `GET /api/entities` and `POST /api/entities` only. |
| `createdAt` | ISO datetime | Creation timestamp |
| `updatedAt` | ISO datetime | Last update timestamp |

```json
{
  "id": "11111111-1111-4111-8111-111111111111",
  "name": "Acme SpA",
  "country": "CL",
  "taxId": "76123456-0",
  "currency": "CLP",
  "ledgerLockDate": "2026-01-31",
  "fiscalYearStartMonth": 1,
  "parentEntityId": null,
  "organizationId": "7c1e4b2a-3d5f-4a6b-8c9d-0e1f2a3b4c5d",
  "createdAt": "2026-02-01T12:00:00.000Z",
  "updatedAt": "2026-02-01T12:00:00.000Z"
}
```

## Domain error codes

| Code | Meaning |
| --- | --- |
| `ENTITY_LOCK_DATE_OVER_SCHEDULED_ENTRY_ERROR` | Lock date would cover a Scheduled Entry |
| `ENTITY_FISCAL_YEAR_START_LOCKED_ERROR` | The Fiscal Year start can't change while a lock date is set. `params.ledgerLockDate` names it |
| `ENTITY_CREATION_COUNTRY_UNKNOWN_ERROR` | The `country` of a new Entity is not a known country code |
| `ENTITY_CREATION_CURRENCY_UNKNOWN_ERROR` | The `currency` of a new Entity is not a known currency code |
| `ENTITY_CREATION_TAX_ID_ALREADY_EXISTS_ERROR` | An Entity with the same `country` and `taxId` already exists |
| `ENTITY_ALREADY_EXISTS_ERROR` | The corrected `country` and `taxId` belong to another Entity |
| `ENTITY_IDENTITY_FIELDS_LOCKED_ERROR` | The Entity has had Ledger Entries, so `country`, `taxId`, and `currency` can't change |
| `ENTITY_NOT_FOUND_ERROR` | Named Entity does not exist or is outside your reach |
| `UNKNOWN_COUNTRY_ERROR` | The corrected `country` is not a known country code |
| `UNKNOWN_CURRENCY_ERROR` | The corrected `currency` is not a known currency code |
| `ENTITY_CREATION_PARENT_NOT_FOUND_ERROR` | The `parentEntityId` of a new Entity does not exist |
| `ENTITY_CREATION_PARENT_IN_ANOTHER_ORGANIZATION_ERROR` | The `parentEntityId` of a new Entity is in another Organization |
| `ENTITY_PARENT_NOT_FOUND_ERROR` | Named parent Entity does not exist |
| `ENTITY_PARENT_IN_ANOTHER_ORGANIZATION_ERROR` | Named parent Entity is in another Organization |
| `ENTITY_SELF_PARENT_ERROR` | An Entity cannot control itself |
| `ENTITY_PARENT_CYCLE_ERROR` | Parent would create a control cycle |
| `ENTITY_MOVE_IN_GROUP_ERROR` | The Entity has a parent Entity or a subsidiary, so it can't move to another Organization |
| `ENTITY_MOVE_USES_ORGANIZATION_DATA_ERROR` | The Entity uses Partners, Dimension Values, Integrations, or Group Accounts of its Organization, so it can't move to another Organization |
| `ENTITY_MOVE_REPRESENTING_PARTNER_IN_USE_ERROR` | Another Entity uses the Partner that represents this Entity, so it can't move to another Organization |
| `ENTITY_MOVE_TAX_IDENTITY_TAKEN_ERROR` | The target Organization already has a Partner with the Entity's tax identity |
| `ENTITY_TAX_IDENTITY_TAKEN_ERROR` | Another Partner of the Organization already holds the Entity's corrected tax identity |
| `ORGANIZATION_NOT_FOUND_ERROR` | Named Organization does not exist or is outside your reach |
| `PERMISSION_DENIED_ERROR` | Your Role in the Organization doesn't allow this action |
| `SUPERADMIN_SESSION_REQUIRED` | The Entity creation, parent change, or Organization move was sent with an API key or token instead of a signed-in session |
| `SUPERADMIN_REQUIRED` | The Entity creation, parent change, or Organization move was sent by a User who is not a Superadmin |

## Status codes

| Status | Meaning |
| --- | --- |
| 200 | Success (GET, PATCH) |
| 204 | Success (PATCH organization) |
| 201 | Created (POST) |
| 400 | Validation error, or a parent change that names the Entity itself or closes a cycle |
| 401 | Unauthenticated |
| 403 | Your Role doesn't allow this action (`PERMISSION_DENIED_ERROR`), or the Entity creation, parent change, or Organization move without a Superadmin session |
| 404 | Entity or Organization not found, or outside your reach |
| 409 | Domain rule violation (see `code`) |
