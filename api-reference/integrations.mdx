An Integration is a linked external system: the credentials, tokens, and configuration Sintropix stores to reach that system on the Entity's behalf. Integrations are the credential side. [Source Feeds](/api-reference/source-feeds) are the recurring pull jobs that actually import data using them.

An Entity can hold more than one Integration at a time (for example, a Bsale document feed alongside a Mercado Pago authorization and a Mercado Libre authorization). Each external account still belongs to a single Entity.

The `sii_mirror` kind is the SII Mirror ("SII Espejo") document Provider. It reads the RCV registers of the Entity's RUT directly from Sintropix's Chilean SII mirror, so it has no credential to paste. You can only connect it on an Entity whose country is Chile.

## The Integration object

The access token is stored encrypted and is never returned on any read.

| Field | Type | Description |
| --- | --- | --- |
| `id` | uuid | Integration id. |
| `entityId` | uuid | Owning Entity. |
| `kind` | `bsale` \| `wasabil` \| `fintoc_fiscal` \| `sii_mirror` \| `mercadopago` \| `mercadolibre` | The external system. |
| `providerRef` | string \| null | The provider's own handle for the connected account (for Bsale, the instance number; for `sii_mirror`, the Entity's RUT; for Mercado Pago and Mercado Libre, the account ID). `null` when a document provider could not determine it at connect time. |
| `documentCount` | integer \| null | Number of documents the provider reported when the credential was verified at connect time. `null` for `mercadopago` and `mercadolibre`, which are OAuth authorizations, not document integrations. |
| `feed` | Source Feed object \| null | The Source Feed that reads through this Integration, in the shape documented on [Source Feeds](/api-reference/source-feeds). `null` when no Feed is configured. |
| `createdAt`, `updatedAt` | ISO 8601 timestamp | Row timestamps. |

## POST `/integrations`

Create an Integration by handing Sintropix a provider-issued access token. The token is verified against the provider once, then stored encrypted.

This route is for document integrations only. Mercado Pago and Mercado Libre use OAuth and are connected from **Settings → Integrations** in the Sintropix app; they cannot be created through this endpoint.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | uuid | Yes | Client-generated id. Retrying the same `POST` with the same id is rejected instead of creating a duplicate. |
| `kind` | `bsale` \| `wasabil` \| `fintoc_fiscal` \| `sii_mirror` | Yes | The external system to link. `mercadopago` and `mercadolibre` are not accepted here. |
| `accessToken` | string | Conditional | The provider's API access token. Required for `bsale` and `wasabil`; whitespace is trimmed and must be non-empty. Omit for `sii_mirror`, which reads Sintropix's SII mirror using the Entity's RUT and takes no credential. |

For `sii_mirror`, Sintropix verifies at connect time that the Entity's country is Chile and that the mirror already follows the Entity's RUT. The connect is refused otherwise (see [Status codes](#status-codes)).

- **Response:** the Integration object (its `feed` is `null` on creation).

```bash
curl -X POST "https://api.sintropix.com/api/entities/$ENTITY_ID/integrations" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "d3e4f5a6-b7c8-4d9e-8f0a-1b2c3d4e5f6a",
    "kind": "bsale",
    "accessToken": "b7f3c9e1a2d4f6081e3c5a7b9d1f2e4c"
  }'
```

```json
{
  "id": "d3e4f5a6-b7c8-4d9e-8f0a-1b2c3d4e5f6a",
  "entityId": "8b0a7d5e-6a3c-4f2b-9e1d-2c4b6a8f0e21",
  "kind": "bsale",
  "providerRef": "12345",
  "documentCount": 355,
  "feed": null,
  "createdAt": "2025-01-02T12:00:00.000Z",
  "updatedAt": "2025-01-02T12:00:00.000Z"
}
```

Connect the SII Mirror on a Chilean Entity with no `accessToken`:

```bash
curl -X POST "https://api.sintropix.com/api/entities/$ENTITY_ID/integrations" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "e7a1b2c3-d4e5-4f6a-8b9c-0d1e2f3a4b5c",
    "kind": "sii_mirror"
  }'
```

## GET `/integrations`

List every Integration for the Entity, including any Mercado Pago or Mercado Libre authorization connected from the app.

- **Response:** array of Integration objects.

## DELETE `/integrations/:integrationId`

Remove an Integration. Any attached Source Feed is removed as part of the same operation. For a Mercado Pago or Mercado Libre Integration, this removes the stored authorization on Sintropix; the grant on the provider's side is not revoked.

- **Response:** the Integration object as it stood before deletion, including its `feed` if it had one.

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | Success on `GET`, `DELETE`. |
| `201` | Integration created. |
| `400` | Validation error, missing `x-audit-actor` on a key-authenticated mutation, or connecting `sii_mirror` on an Entity whose country is not Chile or whose RUT the mirror does not follow. |
| `404` | Entity or Integration not found. |
