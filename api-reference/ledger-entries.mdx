Ledger Entries are the core double-entry transactions in Sintropix. Each entry has a header (date, memo, notes) and at least two balanced lines. This page covers creating, listing, reversing, and unbooking entries, plus Scheduled Entries and line-level updates.

All amounts are integers in the minor unit of the currency (for example, cents). Dates are `YYYY-MM-DD` strings; timestamps are ISO 8601 datetimes.

## GET /api/entities/:entityId/ledger/entries

List Ledger Entries with pagination, filtering, and sorting. Defaults to live entries (`active` and `reversed` statuses).

- **Path param:** `entityId` (UUID)
- **Query params:**

| Param | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `cursor` | UUID | No | — | Last entry id of the previous page |
| `limit` | integer | No | 50 | Page size, max 100 |
| `from` | ISO date | No | — | Earliest entry date |
| `to` | ISO date | No | — | Latest entry date (must be >= from) |
| `search` | string | No | — | Memo search |
| `sort` | enum | No | `date` | `date`, `memo`, or `amount` |
| `direction` | enum | No | `desc` | `asc` or `desc` |
| `statuses` | string | No | `active,reversed` | Comma-separated list of `active`, `deleted`, `reversed`, `scheduled`, `cancelled` |

- **Success response:** a page of entries
- **Status:** 200

| Field | Type | Description |
| --- | --- | --- |
| `entries` | array | Ledger Entries on this page, each with the fields below |
| `nextCursor` | UUID or null | Pass as `cursor` to fetch the next page; `null` on the last page |

Each item in `entries` carries the Ledger Entry fields plus three line-derived totals:

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | Entry id |
| `entityId` | UUID | Owning Entity |
| `entryDate` | ISO date | Transaction date |
| `memo` | string or null | Short description |
| `notes` | string or null | Longer notes |
| `status` | enum | `active`, `deleted`, `reversed`, `scheduled`, or `cancelled` |
| `reversalOfEntryId` | UUID or null | The entry this one reverses; `null` for ordinary entries |
| `createdAt` | ISO datetime | Creation timestamp |
| `updatedAt` | ISO datetime | Last update timestamp |
| `total` | integer | Sum of the entry's debit lines |
| `lineCount` | integer | Number of lines |
| `accountNames` | string[] | Distinct names of the accounts the entry touches, debit-side accounts first |

The first nine fields are the **Ledger Entry** object; other endpoints on this page return it on its own.

```bash
curl "https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/entries?limit=20&sort=date&direction=desc" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## GET /api/entities/:entityId/ledger/entries/:entryId

Get the full detail of a single Ledger Entry, including lines, related invoices, related bank movements, and allocations.

- **Path params:** `entityId` (UUID), `entryId` (UUID)
- **Success response:** the Ledger Entry fields (see the list endpoint above) plus:
- **Status:** 200

| Field | Type | Description |
| --- | --- | --- |
| `reversedByEntryId` | UUID or null | The live reversal that points at this entry, if any |
| `lines` | array | The entry's lines, each with the fields below |
| `relatedInvoices` | array | Invoices this entry books, each with the invoice fields below |
| `relatedMovements` | array | Bank movements this entry books, each with the movement fields below |
| `allocations` | array | Allocations that settle one of this entry's lines, each with the allocation fields below |

Each item in `lines` is a **Ledger Entry Line** (the first eleven fields, which other endpoints return on their own) plus the names the detail view shows:

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | Line id |
| `entryId` | UUID | Parent entry |
| `accountId` | UUID | Ledger Account the line posts to |
| `entityId` | UUID | Owning Entity |
| `functionalAmount` | integer | Nonnegative magnitude in the functional currency |
| `side` | enum | `debit` or `credit` |
| `partnerId` | UUID or null | Counterparty partner |

| `transactionAmount` | integer or null | Amount in the foreign currency |
| `transactionFxRate` | decimal string or null | Rate used for conversion |

| `updatedAt` | ISO datetime | Last update timestamp |
| `accountCode` | string | Code of the account |
| `accountName` | string | Name of the account |
| `accountType` | enum | `asset`, `liability`, `equity`, `income`, `cost_of_goods_sold`, `operating_expense`, `other_income`, or `other_expense` |
| `partnerName` | string or null | Name of the partner |
| `lineDimensionValues` | array | Tags on the line: `{ dimensionId, dimensionValueId, dimensionName, dimensionValueCode, dimensionValueName }` |

Each item in `relatedInvoices`:

## POST /api/entities/:entityId/ledger/entries

Create a new Ledger Entry. The entry must have at least two lines and total debits must equal total credits. The client supplies the idempotency id.

- **Path param:** `entityId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | UUID | Yes | Client-supplied idempotency id |
| `entryDate` | ISO date | Yes | Transaction date |
| `memo` | string or null | Yes | Short description |
| `notes` | string or null | No | Longer notes; trimmed, blank becomes null |
| `newLedgerEntryLines` | array | Yes | At least 2 lines, max 2,000, balanced |

Each line in `newLedgerEntryLines`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `accountId` | UUID | Yes | Ledger Account id |
| `functionalAmount` | integer | Yes | Nonnegative magnitude |
| `side` | enum | Yes | `debit` or `credit` |
| `partnerId` | UUID or null | No | Counterparty partner |
| `transactionCurrency` | string | No | Foreign currency code |
| `transactionAmount` | integer | No | Foreign amount |
| `transactionFxRate` | decimal string | No | Rate as plain decimal string |
| `dimensionValueIds` | UUID[] | No | Default `[]`; tags for this line |

<Note>
  The transaction trio (currency, amount, rate) must be provided together or omitted together. The rate is a plain decimal string, never a float.
</Note>

## PATCH /api/entities/:entityId/ledger/entries/:entryId

Update an entry's header fields (date, memo, notes). At least one field must be provided.

- **Path params:** `entityId` (UUID), `entryId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `entryDate` | ISO date | No | New transaction date |
| `memo` | string or null | No | New memo |
| `notes` | string or null | No | New notes; trimmed, blank becomes null |

- **Success response:** the updated Ledger Entry object (see the list endpoint)
- **Status:** 200

```bash
curl -X PATCH https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/entries/$ENTRY_ID \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{"memo": "Updated description"}'
```

## POST /api/entities/:entityId/ledger/entries/:entryId/reverse

Reverse a live Ledger Entry by posting a mirror entry. The reversal date must be after the original entry date and after the ledger lock date.

- **Path params:** `entityId` (UUID), `entryId` (UUID)
- **Body:**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | UUID | Yes | Client-supplied idempotency id for the reversal entry |
| `entryDate` | ISO date | Yes | Reversal date |

- **Success response:** every row the reversal changed
- **Status:** 201

| Field | Type | Description |
| --- | --- | --- |
| `reversalEntry` | object | The mirror entry just posted: Ledger Entry fields plus `ledgerEntryLines` (same shape as the create response) |
| `reversedEntry` | object | The original entry as it now stands, with `status` set to `reversed` |
| `severedInvoices` | array | Invoices whose booking link was cut (invoice fields as in the entry detail, without `partnerName`) |
| `severedMovements` | array | Bank movements whose booking link was cut (movement fields as in the entry detail, without `bankAccountCurrency`, `bankAccountLedgerAccountId`, and `partnerName`) |
| `settledChainEntries` | array | Ledger Entry objects whose status changed because a reversal chain was settled, in the order they changed; empty when nothing else changed |

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/entries/$ENTRY_ID/reverse \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{
    "id": "44444444-4444-4444-8444-444444444444",
    "entryDate": "2026-01-20"
  }'
```

## DELETE /api/entities/:entityId/ledger/entries/:entryId

Unbook (soft-delete) a Ledger Entry. The entry status becomes `deleted`. This severs any linked invoices, bank movements, and allocations. If the entry is a reversal, the chain behind it is settled back to its prior state.

- **Path params:** `entityId` (UUID), `entryId` (UUID)
- **Success response:** every row the unbook changed
- **Status:** 200

| Field | Type | Description |
| --- | --- | --- |
| `unbookedEntry` | object | The Ledger Entry object with `status` set to `deleted` |
| `severedInvoices` | array | Invoices whose booking link was cut (same shape as in the reverse response) |
| `severedMovements` | array | Bank movements whose booking link was cut (same shape as in the reverse response) |
| `settledChainEntries` | array | Ledger Entry objects whose status changed because a reversal chain was settled; empty when nothing else changed |

```bash
curl -X DELETE https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/entries/$ENTRY_ID \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent"
```

## Scheduled Entries

### POST /api/entities/:entityId/ledger/scheduled-entries

Schedule a Ledger Entry for future booking. The entry date must be in the future. Scheduled entries cannot carry transaction currency lines.

- **Path param:** `entityId` (UUID)
- **Body:** the same fields as `POST /api/entities/:entityId/ledger/entries` above
- **Success response:** the Ledger Entry fields plus `ledgerEntryLines` (same shape as the create response), with `status` set to `scheduled`
- **Status:** 201

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/scheduled-entries \
  -H "Content-Type: application/json" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -d '{
    "id": "55555555-5555-4555-8555-555555555555",
    "entryDate": "2026-03-01",
    "memo": "Future rent",
    "notes": null,
    "newLedgerEntryLines": [
      { "accountId": "11111111-1111-4111-8111-111111111111", "functionalAmount": 500, "side": "debit" },
      { "accountId": "22222222-2222-4222-8222-222222222222", "functionalAmount": 500, "side": "credit" }
    ]
  }'
```

### POST /api/entities/:entityId/ledger/scheduled-entries/:entryId/book

Book a Scheduled Entry immediately. The entry date must be on or before today.

- **Path params:** `entityId` (UUID), `entryId` (UUID)
- **Success response:** the Ledger Entry fields plus `ledgerEntryLines` (same shape as the create response), with `status` set to `active`
- **Status:** 200

```bash
curl -X POST https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/scheduled-entries/$ENTRY_ID/book \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent"
```

## Ledger Lines

List Ledger Entry Lines. Defaults to live entries only. Optionally filter by partner.

- **Path param:** `entityId` (UUID)
- **Query params:**

| Param | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `partnerId` | UUID | No | — | Narrow to one partner's lines |
| `statuses` | string | No | `active,reversed` | Comma-separated list of `active`, `deleted`, `reversed`, `scheduled`, `cancelled` |

- **Success response:** an array of Ledger Entry Line objects (see the entry detail endpoint), each extended with:
- **Status:** 200

| Field | Type | Description |
| --- | --- | --- |
| `openAmount` | integer or null | Amount not yet settled by allocations; `null` on accounts that do not track open items |

```bash
curl "https://api.sintropix.com/api/entities/$ENTITY_ID/ledger/lines?partnerId=$PARTNER_ID" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

### GET /api/entities/:entityId/ledger/open-item-lines

List Open Item lines for an Open-Item Account with pagination. Shows unsettled lines by default.

- **Path param:** `entityId` (UUID)
- **Query params:**

| Param | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |

- **Success response:** a page of open-item lines
- **Status:** 200

| Field | Type | Description |

