---
title: "Sintropix Onboarding API: Provision Users and Grant Memberships"
sidebarTitle: "Onboarding"
description: "Staff-only endpoints to create Users, look them up by email, grant Organization Memberships with a Role, mint set-password links, and revoke sessions."
---

The Onboarding API is how Sintropix staff provision new Users and control which Organizations they can access. Every route below is restricted to Users with `role = staff`. Public sign-up is disabled, so User creation happens only through this surface, and set-password links are minted here and delivered to the client through the staff member's existing channel because Sintropix does not send email.

<Warning>
  Staff-only. A client-role caller (session or API key) receives `403` on every route below.
</Warning>

## POST `/onboarding/users`

Create a User. This is the only place a User's global role is assigned. Access to client Entities comes from the Organization Memberships granted below.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | A valid email address. Must be unique across all Users. |
| `name` | string | Yes | Display name. Minimum 1 character. |
| `role` | enum | Yes | One of `staff` or `client`. |

**Response** `200`

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | The new User's id. Use it in the `:userId` path segment of the routes below. |
| `email` | string | The email supplied on creation. |
| `name` | string | The display name supplied on creation. |
| `role` | enum | `staff` or `client`. |

```bash
curl -X POST "https://api.sintropix.com/api/onboarding/users" \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{
    "email": "ana.perez@example.com",
    "name": "Ana Perez",
    "role": "client"
  }'
```

```json
{
  "id": "0192a3b4-c5d6-7e8f-9a0b-1c2d3e4f5a6b",
  "email": "ana.perez@example.com",
  "name": "Ana Perez",
  "role": "client"
}
```

## GET `/onboarding/users`

Look up a User by email. Use this to recover a User's id when all you hold is their address.

**Query params**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | The email address to look up. Must be a valid email. |

**Response** `200`: the same User object returned by `POST /onboarding/users` (`id`, `email`, `name`, `role`).

```bash
curl "https://api.sintropix.com/api/onboarding/users?email=ana.perez%40example.com" \
  --cookie cookies.txt
```

## GET `/onboarding/users/:userId/memberships`

List the Organization Memberships a User holds. Each Membership gives the User one Role across every Entity of that [Organization](/api-reference/organizations).

**Response** `200`: an array of Memberships.

| Field | Type | Description |
| --- | --- | --- |
| `role` | enum | `staff`, `client`, or `viewer`. See [Access and roles](/api-reference/overview#access-and-roles). |
| `organization` | object | `{ id, name }` of the Organization. |

```bash
curl "https://api.sintropix.com/api/onboarding/users/$USER_ID/memberships" \
  --cookie cookies.txt
```

```json
[
  {
    "role": "client",
    "organization": { "id": "7c1e4b2a-3d5f-4a6b-8c9d-0e1f2a3b4c5d", "name": "Grupo Acme" }
  }
]
```

## POST `/onboarding/users/:userId/memberships`

Grant a User a Membership in an Organization with one Role. The User reaches every Entity of the Organization, including Entities added to it later. A User holds at most one Membership per Organization.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `organizationId` | UUID | Yes | The Organization to grant access to. Must be an existing Organization. |
| `role` | enum | Yes | `staff`, `client`, or `viewer`. |

- **Status:** `204`.

```bash
curl -X POST "https://api.sintropix.com/api/onboarding/users/$USER_ID/memberships" \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{ "organizationId": "7c1e4b2a-3d5f-4a6b-8c9d-0e1f2a3b4c5d", "role": "client" }'
```

## PATCH `/onboarding/users/:userId/memberships/:organizationId`

Change the Role of an existing Membership.

**Body**

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `role` | enum | Yes | `staff`, `client`, or `viewer`. |

- **Status:** `204`.

```bash
curl -X PATCH "https://api.sintropix.com/api/onboarding/users/$USER_ID/memberships/$ORGANIZATION_ID" \
  --cookie cookies.txt \
  -H "Content-Type: application/json" \
  -d '{ "role": "viewer" }'
```

## DELETE `/onboarding/users/:userId/memberships/:organizationId`

Revoke a User's Membership in an Organization. The User loses access to every Entity of the Organization. No request body.

- **Status:** `204`.

```bash
curl -X DELETE "https://api.sintropix.com/api/onboarding/users/$USER_ID/memberships/$ORGANIZATION_ID" \
  --cookie cookies.txt
```

## POST `/onboarding/users/:userId/set-password-link`

Mint a one-time link the User can follow to set (or reset) their password. Delivery is manual: the staff member sends the link to the client over their existing channel (Sintropix does not send transactional email). No request body.

**Response** `200`

| Field | Type | Description |
| --- | --- | --- |
| `link` | URL | The one-time set-password link to relay to the User. |

```bash
curl -X POST "https://api.sintropix.com/api/onboarding/users/$USER_ID/set-password-link" \
  --cookie cookies.txt
```

```json
{
  "link": "https://app.sintropix.com/set-password?token=eyJhbGciOiJIUzI1NiJ9..."
}
```

## POST `/onboarding/users/:userId/revoke-sessions`

Revoke every active session for a User, forcing a fresh sign-in on their next request. Use after a suspected credential compromise. No request body.

- **Status:** `204`.

```bash
curl -X POST "https://api.sintropix.com/api/onboarding/users/$USER_ID/revoke-sessions" \
  --cookie cookies.txt
```

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | Success on `POST /users`, `GET /users`, `GET /memberships`, `POST /set-password-link`. |
| `204` | Success on Membership grant, role change, revoke, and session revocation. |
| `400` | Validation error, including a `:userId` that is not a UUID. |
| `403` | Caller is not `staff`. |
| `404` | User or Organization not found (`ORGANIZATION_NOT_FOUND_ERROR`), or no Membership to change or revoke (`ORGANIZATION_MEMBERSHIP_NOT_FOUND_ERROR`). |
| `409` | The User already holds a Membership in this Organization (`ORGANIZATION_MEMBERSHIP_ALREADY_EXISTS_ERROR`). |
