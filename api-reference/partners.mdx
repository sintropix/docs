A Partner is any counterparty on an Entity's books: a customer, a supplier, an employee, or a tax authority. Partners are referenced from Invoices, Ledger Lines with Open Items, and Bank Movement matches. This page covers Partner CRUD, the paginated Partner listing, and vendor Booking Templates.

Amounts are integers in the minor units of the Entity's functional currency. Timestamps are ISO 8601.

<Note>
  **Entities with Books.** When the Entity has at least one [Book](/api-reference/books), `GET /partners/pages` requires a `bookId` query parameter — the `openReceivable` and `openPayable` totals on the page rows are then computed inside that Book. `GET /partners` and the Partner rows returned by create, update, and delete stay outside the rule and surface open totals across every Book.
</Note>

## GET `/partners`

List every Partner for the Entity, each row enriched with Open Item totals (unsettled AR and AP balances).

**Response:** an array of Partner objects.

| Field | Type | Description |
| --- | --- | --- |
| `id` | uuid | Partner id. |
| `entityId` | uuid | Owning Entity. |
| `name` | string | Display name. |
| `type` | string or null | `customer`, `vendor`, or `employee`. |
| `defaultPurchaseAccountId` | uuid or null | Ledger Account proposed when booking this vendor's purchase invoices. |
| `booksAutomatically` | boolean | Whether Sintropix books this vendor's new purchase invoices from its [Booking Template](#booking-templates). Always `false` for a Partner without a template. |
| `legalName` | string or null | Registered legal name. |
| `country` | string or null | ISO 3166-1 alpha-2 code of the tax registration. |
| `taxId` | string or null | Tax registration number. Chilean RUTs are stored as digits, hyphen, check digit (`76123456-0`). |
| `openReceivable` | integer | Unsettled amount this Partner owes the Entity. |
| `openPayable` | integer | Unsettled amount the Entity owes this Partner. |
| `createdAt` | timestamp | Creation time. |
| `updatedAt` | timestamp | Last update time. |

```bash
curl "https://api.sintropix.com/api/entities/$ENTITY_ID/partners" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## GET `/partners/pages`

Paginated Partner listing for UI use.

**Query parameters.** Unknown parameters are rejected with `400`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `cursor` | uuid | No | The `nextCursor` of the previous page. Omit for the first page. |
| `limit` | integer | No | Rows per page, 1 to 100. Default `50`. |
| `search` | string | No | Case-insensitive contains-match on `name`, `legalName`, `taxId`, and the default purchase account's code and name. At most 100 characters. |
| `type` | string | No | `customer`, `vendor`, or `employee`. |
| `country` | string | No | ISO 3166-1 alpha-2 code. |
| `openReceivableMin` | integer | No | Inclusive lower bound on `openReceivable`. |
| `openReceivableMax` | integer | No | Inclusive upper bound; must not be below the minimum. |
| `openPayableMin` | integer | No | Inclusive lower bound on `openPayable`. |
| `openPayableMax` | integer | No | Inclusive upper bound; must not be below the minimum. |
| `defaultPurchaseAccountFilter` | string | No | `all`, `assigned`, or `missing`. Default `all`. Requires `type=vendor` unless `all`. |
| `defaultPurchaseAccountId` | uuid | No | Keep only vendors with this default purchase account. Requires `type=vendor`. |
| `defaultPurchaseAccountClassification` | string | No | `expense`, `fixed_asset`, or `missing`. Requires `type=vendor`. |
| `groupBy` | string | No | `none`, `type`, `country`, `defaultPurchaseAccount`, or `defaultPurchaseAccountClassification`. Default `none`. The last two require `type=vendor`. |
| `sort` | string | No | `name`, `type`, `legalName`, `taxId`, `country`, `openReceivable`, `openPayable`, or `defaultPurchaseAccount`. Default `name`. |
| `sortDirection` | string | No | `asc` or `desc`. Default `asc`. |
| `bookId` | uuid | Conditional | Required when the Entity has at least one Book; must be omitted otherwise. |

**Response**

| Field | Type | Description |
| --- | --- | --- |
| `partners` | array | The Partner rows on this page (see below). |
| `nextCursor` | uuid or null | Pass as `cursor` to fetch the next page. Null on the last page. |
| `totalCount` | integer | Partners matching the filters, across all pages. |
| `withoutDefaultPurchaseAccountCount` | integer | Of those, how many have no default purchase account. |

Each element of `partners` is a **Partner row**: every field of the Partner object above, plus:

| Field | Type | Description |
| --- | --- | --- |
| `countryName` | string or null | Name of `country`. |
| `defaultPurchaseAccountCode` | string or null | Code of the default purchase account. |
| `defaultPurchaseAccountName` | string or null | Name of the default purchase account. |
| `defaultPurchaseAccountClassification` | string | `expense`, `fixed_asset`, or `missing`. |
| `group` | object or null | Null unless `groupBy` was requested. Contains `by`, `value`, `key` (string), `partnerCount` (integer), `openReceivable` (integer), `openPayable` (integer), and `startsGroup` (boolean, true on the first row of each group). |

The type of `group.value` depends on `group.by`:

| `by` | `value` |
| --- | --- |
| `type` | `customer`, `vendor`, `employee`, or null |
| `country` | string or null |
| `defaultPurchaseAccount` | string or null |
| `defaultPurchaseAccountClassification` | `expense`, `fixed_asset`, or `missing` |

```bash
curl "https://api.sintropix.com/api/entities/$ENTITY_ID/partners/pages?type=vendor&defaultPurchaseAccountFilter=missing&limit=25" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

## POST `/partners`

Create a Partner.

**Body.** Unknown keys are rejected with `400`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | uuid | Yes | Caller-generated id. Retrying with the same id is answered `409`, so a retried request never creates a second Partner. |
| `name` | string | Yes | Non-empty display name. |
| `type` | string or null | No | `customer`, `vendor`, or `employee`. |
| `legalName` | string or null | No | Non-empty if sent. |
| `country` | string or null | No | ISO 3166-1 alpha-2 code known to Sintropix. |
| `taxId` | string or null | No | Tax registration number. When `country` is `CL` the value must be a valid RUT; separators and dots are accepted and it is stored in canonical form (`76.123.456-0` becomes `76123456-0`). |
| `defaultPurchaseAccountId` | uuid or null | No | Only for `type: "vendor"`. The account must be an expense-type Ledger Account or a fixed-asset account. |

A `country` and `taxId` pair must be unique within the Entity (`409`).

**Response** (`201`): the created Partner row, as `GET /partners/pages` would list it.

```bash
curl -X POST "https://api.sintropix.com/api/entities/$ENTITY_ID/partners" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "0b6c0f2e-5a4d-4e8f-b1c3-7d9e2a4f6c88",
    "name": "Servicios Cloud SpA",
    "type": "vendor",
    "legalName": "Servicios Cloud SpA",
    "country": "CL",
    "taxId": "76123456-0",
    "defaultPurchaseAccountId": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d"
  }'
```

## PATCH `/partners/:partnerId`

Update Partner attributes.

**Body:** any subset of the fields below. At least one is required; unknown keys are rejected with `400`. Send `null` to clear a nullable field.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | No | Non-empty. |
| `type` | string or null | No | `customer`, `vendor`, or `employee`. Changing away from `vendor` requires clearing `defaultPurchaseAccountId` and removing any Booking Template. |
| `legalName` | string or null | No | Non-empty if sent. |
| `country` | string or null | No | ISO 3166-1 alpha-2 code. |
| `taxId` | string or null | No | Same RUT rule as on create when the resulting country is `CL`. |
| `defaultPurchaseAccountId` | uuid or null | No | Only for vendors; expense-type or fixed-asset account. |
| `booksAutomatically` | boolean | No | Turn automatic booking from the [Booking Template](#booking-templates) on or off. Only for vendors. `true` requires a saved template (`409`). Not accepted on create: a new Partner starts with `false`. |

**Response:** `{ "partner": <Partner row>, "previousPartner": <Partner row> }`, the row after and before the update.

```bash
curl -X PATCH "https://api.sintropix.com/api/entities/$ENTITY_ID/partners/$PARTNER_ID" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{ "legalName": "Servicios Cloud Limitada", "defaultPurchaseAccountId": null }'
```

## DELETE `/partners/:partnerId`

Delete a Partner. Partners with outstanding Open Items or referenced Ledger Lines are refused.

**Response:** the deleted Partner row, as `GET /partners/pages` listed it.

## Booking Templates

A Booking Template tells Sintropix how to book a vendor's purchase invoices. It is an ordered list of lines. Each line takes one amount from the Invoice or its DTE and posts it to a Ledger Account on a side. With the vendor's `booksAutomatically` switch on, Sintropix books each new purchase invoice of that vendor when it is created, but only when the Invoice fits the template exactly.

Use a template for a vendor whose invoices you always book with the same entry shape, such as a hosting provider billed to one expense account plus IVA. Invoices that do not fit land unbooked, and you book them by hand with [`POST /invoices/:invoiceId/book`](/api-reference/invoices).

Templates and the switch are for Partners of `type: "vendor"` only. The Partner's default purchase account is unaffected.

### Template lines

| Field | Type | Description |
| --- | --- | --- |
| `amountSource` | string | Where the line's amount comes from: `invoice_total` (the Invoice `total`), `dte_net_amount`, `dte_exempt_amount`, or `dte_tax_amount` (the DTE's `netAmount`, `exemptAmount`, or `taxAmount`, where `taxAmount` is IVA). |
| `accountId` | uuid | Ledger Account of the Entity the line posts to. |
| `side` | string | `debit` or `credit`. |

A template needs at least 2 and at most 2000 lines. Exactly one line uses `invoice_total`: the **Control Line**. It must follow the control line rules of [Book invoice](/api-reference/invoices) for a payable invoice: a `credit` on an open-item payable liability account. No other line may post to the Control Line's account.

While a template uses an account as its Control Line, that account's type, subtype, and tracking cannot change (`LEDGER_ACCOUNT_FACT_PINNED_ERROR`). An account any template line uses cannot be deleted.

### When an Invoice is booked automatically

Sintropix books a new Invoice from the template only when all of these hold:

1. The create request sent no `bookingEntryWithLines`. An explicit booking always wins.
2. The Invoice is `direction: "payable"` and `documentKind: "invoice"`. Credit notes are never booked automatically.
3. The same request creates the DTE. An Invoice whose DTE is attached later is not booked.
4. The Invoice and its DTE are in the Entity's functional currency, and the Invoice has no Review Status.
5. The vendor has `booksAutomatically` set to `true`.
6. Every line's source has a value on the DTE, and none is negative.
7. The Control Line amount is not `0`. Other lines with an amount of `0` are dropped.
8. The remaining lines balance exactly. There is no rounding tolerance.

The booking follows every rule of Book invoice, including the Lock Date. If any condition fails, the Invoice and its DTE are still created, unbooked, and Sintropix stores no reason. In `POST /invoices/bulk` and the source-feed sync, one Invoice that does not fit never blocks the others. Invoices that exist before you turn the switch on are not booked.

The [Audit Trail](/api-reference/audit-trail) credits an automatic booking to the system, with the declared actor `booking-template`.

### GET `/partners/:partnerId/booking-template`

Read a Partner's template.

**Response:** `{ "partner": <Partner row>, "lines": [<line>] }`. The Partner row has the shape `GET /partners/pages` lists. `lines` is empty when the Partner has no template.

### PUT `/partners/:partnerId/booking-template`

Save a template. The body replaces the whole list of lines; the order of `lines` is the order of the template.

**Body:** `{ "lines": [<line>] }`. Unknown keys are rejected with `400`.

**Response:** the saved template, in the shape `GET` answers.

```bash
curl -X PUT "https://api.sintropix.com/api/entities/$ENTITY_ID/partners/$PARTNER_ID/booking-template" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{
    "lines": [
      { "amountSource": "dte_net_amount", "accountId": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d", "side": "debit" },
      { "amountSource": "dte_tax_amount", "accountId": "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f", "side": "debit" },
      { "amountSource": "invoice_total", "accountId": "3e7a9c1b-2d4f-4a6e-8b0c-1d2e3f4a5b6c", "side": "credit" }
    ]
  }'
```

With this template, an Invoice with a `total` of `1190000` and a DTE stating `netAmount` `1000000` and `taxAmount` `190000` is booked. The net and tax lines are debited, and the payable is credited. A DTE whose amounts do not add up to the total leaves the Invoice unbooked.

Then turn the switch on:

```bash
curl -X PATCH "https://api.sintropix.com/api/entities/$ENTITY_ID/partners/$PARTNER_ID" \
  -H "x-api-key: $SINTROPIX_API_KEY" \
  -H "x-audit-actor: my-agent" \
  -H "Content-Type: application/json" \
  -d '{ "booksAutomatically": true }'
```

### DELETE `/partners/:partnerId/booking-template`

Remove the template. This also turns `booksAutomatically` off.

**Response:** the Partner and its now empty `lines`, in the shape `GET` answers.

### Error codes

| Code | Status | Meaning |
| --- | --- | --- |
| `PARTNER_BOOKING_TEMPLATE_REQUIRES_VENDOR_ERROR` | `409` | The Partner is not a vendor, or a `PATCH` would change the type of a Partner that holds a template. |
| `PARTNER_BOOKS_AUTOMATICALLY_REQUIRES_BOOKING_TEMPLATE_ERROR` | `409` | `booksAutomatically: true` was sent for a Partner without a template. |
| `CONTROL_ACCOUNT_IN_ENTRY_LINES_MORE_THAN_ONCE_ERROR` | `400` | Another line posts to the Control Line's account. |

A Control Line on the wrong side or on an account Book invoice refuses as a payable control account is answered with the same error Book invoice returns.

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | Success on `GET`, `PATCH`, `DELETE`. `DELETE` answers with the deleted row. |
| `201` | Partner created. |
| `400` | Validation error (including an invalid RUT or an unknown country), or missing `x-audit-actor` on a key-authenticated mutation. |
| `404` | Entity or Partner not found. |
| `409` | Partner id or tax identity already exists, the Partner has open items or references and cannot be deleted, or a Booking Template rule is violated. |
