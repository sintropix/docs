The Reference Data API exposes the static catalogs Sintropix uses across every Entity: the list of supported Countries, the list of supported Currencies, and the list of Chilean Banks. These are shared, Entity-independent lookups; use them to render pickers and to validate codes before writes.

## GET `/countries`

Return every supported Country. No query parameters.

**Response** `200`: an array of Country objects.

| Field | Type | Description |
| --- | --- | --- |
| `code` | string | ISO 3166-1 alpha-2 code, for example `CL`. This is the value other endpoints accept as a country. |
| `name` | string | Display name of the country. |

```bash
curl "https://api.sintropix.com/api/countries" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

```json
[
  { "code": "CL", "name": "Chile" },
  { "code": "US", "name": "United States" }
]
```

## GET `/currencies`

Return every supported Currency (ISO 4217 codes plus display metadata). No query parameters.

**Response** `200`: an array of Currency objects.

| Field | Type | Description |
| --- | --- | --- |
| `code` | string | ISO 4217 code, for example `CLP`. This is the value other endpoints accept as a currency. |
| `decimalPlaces` | integer | Number of minor-unit decimal places amounts in this currency carry (`0` for CLP, `2` for USD). |
| `name` | string | Display name of the currency. |

```bash
curl "https://api.sintropix.com/api/currencies" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

```json
[
  { "code": "CLP", "decimalPlaces": 0, "name": "Chilean Peso" },
  { "code": "USD", "decimalPlaces": 2, "name": "US Dollar" }
]
```

## GET `/banks`

Return every Chilean Bank a Partner's [Bank Details](/api-reference/partners#bank-details) can name. No query parameters.

The catalog covers every institution a transfer can reach by its CMF code: the banks, including digital banks such as Tanner Banco Digital (`062`) and Tenpo Bank Chile (`063`), the savings cooperatives, and the prepaid card issuers payees are paid into, such as Mercado Pago (`875`), Global66 (`738`), Tenpo (`730`), and Copec Pay (`741`). A prepaid card issuer goes by the brand payees know.

**Response** `200`: an array of Bank objects.

| Field | Type | Description |
| --- | --- | --- |
| `code` | string | The bank's three-digit code from the CMF (Comisión para el Mercado Financiero), for example `016`. This is the value Bank Details accept as `bankCode`. |
| `name` | string | Display name of the bank. |

```bash
curl "https://api.sintropix.com/api/banks" \
  -H "x-api-key: $SINTROPIX_API_KEY"
```

```json
[
  { "code": "001", "name": "Banco de Chile" },
  { "code": "016", "name": "Banco de Crédito e Inversiones" },
  { "code": "672", "name": "Coopeuch" },
  { "code": "875", "name": "Mercado Pago" }
]
```

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | Success. |
| `401` | No valid credential. |
