title: "Transactions API: Query and Create Financial Entries"
sidebarTitle: "Transactions"
description: "Query bank transactions, journal entries, payroll, and expenses across entities — or create manual journal entries — via the Sintropix Transactions API."
---

The Transactions API gives you read and write access to every financial movement recorded in Sintropix — whether it arrived from a connected bank integration, was generated by your payroll provider, or was entered manually. You can filter transactions by entity, date range, currency, type, and reconciliation status, and you can create new manual journal entries directly over the API.

Reading transactions requires the `read:financials` scope. Creating transactions requires the `write:transactions` scope.

---

## GET /transactions

List transactions across your organization with flexible filtering.

```bash
curl "https://api.sintropix.com/v1/transactions?entity_id=ent_def456&start_date=2025-01-01&end_date=2025-01-31" \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY"
```

### Query Parameters

<ParamField query="entity_id" type="string" required>
  Filter transactions to a specific entity. Pass the entity's `id` from the Entities API.
</ParamField>

<ParamField query="start_date" type="string">
  Filter to transactions on or after this date. ISO 8601 format: `YYYY-MM-DD`.
</ParamField>

<ParamField query="end_date" type="string">
  Filter to transactions on or before this date. ISO 8601 format: `YYYY-MM-DD`.
</ParamField>

<ParamField query="currency" type="string">
  Filter to transactions denominated in a specific currency. ISO 4217 code (e.g., `CLP`, `USD`, `MXN`).
</ParamField>

<ParamField query="type" type="string">
  Filter by transaction type. One of: `bank_transaction`, `journal_entry`, `payroll`, `expense`, `invoice`.
</ParamField>

<ParamField query="reconciliation_status" type="string">
  Filter by reconciliation state. One of: `matched`, `needs_review`, `unmatched`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of transactions to return per page. Maximum `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor returned by the previous response. Omit on the first request.
</ParamField>

### Response Fields

<ResponseField name="id" type="string">
  Unique transaction identifier (e.g., `txn_xyz789`).
</ResponseField>

<ResponseField name="entity_id" type="string">
  The entity this transaction belongs to.
</ResponseField>

<ResponseField name="type" type="string">
  Transaction type: `bank_transaction`, `journal_entry`, `payroll`, `expense`, or `invoice`.
</ResponseField>

<ResponseField name="amount" type="number">
  Transaction amount in the transaction currency. Positive values represent inflows; negative values represent outflows.
</ResponseField>

<ResponseField name="currency" type="string">
  ISO 4217 currency code for this transaction.
</ResponseField>

<ResponseField name="date" type="string">
  ISO 8601 date of the transaction (`YYYY-MM-DD`).
</ResponseField>

<ResponseField name="description" type="string">
  Human-readable description of the transaction, as imported from the source or entered manually.
</ResponseField>

<ResponseField name="counterparty" type="string">
  Name of the counterparty (vendor, customer, employee) associated with this transaction, if available.
</ResponseField>

<ResponseField name="reconciliation_status" type="string">
  Current reconciliation state: `matched`, `needs_review`, or `unmatched`.
</ResponseField>

<ResponseField name="source" type="string">
  The integration that created this transaction (e.g., `Banco de Chile`, `Buk`, `Stripe`), or `manual` if created via the API or Sintropix UI.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when Sintropix ingested or created this transaction.
</ResponseField>

## POST /transactions

Create a manual journal entry in Sintropix. Each journal entry must be **balanced** — the sum of all debit amounts must equal the sum of all credit amounts across its lines.

```bash
curl -X POST https://api.sintropix.com/v1/transactions \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "entity_id": "ent_def456",
    "date": "2025-01-15",
    "description": "Revenue recognition — Contract C-0088, January tranche",
    "reference": "REV-REC-2025-01-C0088",
    "lines": [
      {
        "account_id": "acc_cash_001",
        "debit": 3000000,
        "credit": null,
        "currency": "CLP"
      },
      {
        "account_id": "acc_revenue_002",
        "debit": null,
        "credit": 3000000,
        "currency": "CLP"
      }
    ]
  }'
```

### Request Body

<ParamField body="entity_id" type="string" required>
  The entity in which to create the journal entry.
</ParamField>

<ParamField body="date" type="string" required>
  Accounting date of the entry. ISO 8601 format: `YYYY-MM-DD`.
</ParamField>

<ParamField body="description" type="string" required>
  A human-readable description of the entry visible in the general ledger.
</ParamField>

<ParamField body="lines" type="array" required>
  Array of debit and credit lines. Must contain at least two lines, and total debits must equal total credits.

  <Expandable title="Line object fields">
    <ParamField body="account_id" type="string" required>
      The chart-of-accounts ID for this line. Retrieve account IDs from the Entities API or the Sintropix UI.
    </ParamField>
    <ParamField body="debit" type="number">
      Debit amount. Set to `null` if this line is a credit.
    </ParamField>
    <ParamField body="credit" type="number">
      Credit amount. Set to `null` if this line is a debit.
    </ParamField>
    <ParamField body="currency" type="string" required>
      ISO 4217 currency code for this line (e.g., `CLP`, `USD`).
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="reference" type="string">
  Optional internal reference code for this entry (e.g., a contract number or purchase order). Searchable in Sintropix.
</ParamField>

  "data": {
    "id": "txn_new123",
    "entity_id": "ent_def456",
    "type": "journal_entry",
    "date": "2025-01-15",

      }

<Warning>
  If the lines in your request do not balance (total debits ≠ total credits), the API returns `400 Bad Request` with error code `UNBALANCED_JOURNAL_ENTRY`. Multi-currency entries are validated after converting all lines to the entity's functional currency using the daily FX rate for the entry's date.
</Warning>
