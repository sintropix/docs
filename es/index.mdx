Sintropix expone una API HTTP al mismo backend ERP que usan la aplicación web y Erwin, el asistente de IA integrado en el producto. Cada recurso, desde asientos contables y movimientos bancarios hasta facturas e informes, está disponible como un endpoint JSON acotado a una Entidad, de modo que agentes e integraciones pueden leer y escribir datos financieros directamente.

## Para agentes de IA

La API está diseñada para que la operen agentes:

- Cada ruta de negocio está acotada a una sola Entidad (`/api/entities/{entityId}/...`), así que un agente que trabaja con varias empresas siempre hace explícito el destino.
- Las solicitudes y respuestas se validan de extremo a extremo, por lo que los nombres de campo, tipos y enumeraciones son estables en todos los endpoints.
- Los errores devuelven una estructura consistente con códigos legibles por máquina para reintentos y ramificaciones.
- El [registro de auditoría](/api-reference/audit-trail) guarda cada escritura, así que las acciones de los agentes son rastreables.

Empieza por la [descripción general de la API](/es/api-reference/overview) y [Obtener una clave de API](/es/guides/api-keys), y luego ve directo al recurso que necesites.
